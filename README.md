# Cybersecurity-Writeups

A collection of cybersecurity notes, walkthroughs, methodology guides, and practical write-ups created during my learning journey in ethical hacking, penetration testing, web security, and network security.

## About

This repository serves as a personal knowledge base where I document:

* Hack The Box (HTB) machines and challenges
* Web application security concepts
* Network security assessments
* Penetration testing methodologies
* Enumeration techniques
* Vulnerability analysis
* Tools, commands, and cheat sheets

The primary goal is to reinforce learning through documentation while creating a reference that can be revisited in future engagements.
