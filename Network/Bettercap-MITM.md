# Bettercap MITM Practice

## objective
understand man in the middle attack in local network

## tools
- bettercap
- kali linux

## steps
1. open bettercap
2. select network interface
3. run net.probe to find devices
4. identify target ip
5. start arp spoofing
6. enable packet sniffing

## result
i can see network traffic between target and router

## what i learn
- how mitm attack works
- arp spoofing concept
- attacker can see data if not encrypted
- importance of https

## note
this is done only in lab environment for learning purpose
